# cnki v0.1.0

Date: 2026-10-08

首个发布版本. cnki 把中国知网的检索能力搬到命令行: 检索, 分组筛选, 文献详情与题录导出都在终端完成, 交付物是单个 Go 二进制, 没有运行时依赖.

开始之前需要理解一件事. 知网对检索站点实施滑块验证, 而且这个验证绑定在 cookie 上而不是 IP 上 —— 同一个 IP 下, 浏览器过了验证, 纯 HTTP 请求依然会被拦回验证页. 所以本工具需要一个取到会话的入口, 这是 `cnki auth login` 存在的唯一理由. 取到之后所有检索都走纯 HTTP 复用该会话, 速度与浏览器一致, 也不再需要浏览器.

## Highlights

- 一次交互换长期可用: `cnki auth login` 打开受控浏览器窗口, 在里面完成滑块或任意形式的登录, 会话随即被保存; 之后检索不再碰浏览器, 失效时自动重新拉起验证窗口.
- 覆盖五种检索入口: 一框式, 高级, 专业, 句子与作者发文检索, 可限定到知网的 33 个文献库.
- 结果可以直接用来写作: 题录导出支持 RIS 与 BibTeX 本地渲染, 也支持知网侧的 GB/T 7714, MLA, APA, EndNote, NoteExpress 等格式.
- 输出对人和对机器都友好: 默认等宽表格, 加 `--json` 得到结构化数据, 表格按东亚字符宽度对齐, 日志只写 stderr, 因此 `--json` 的结果可以直接交给 `jq`.

## Upgrade Notes

这是首个发布版本, 不存在需要迁移的旧版本与旧配置.

1. 安装:

   ```shell
   go install github.com/azazo1/cnki-cli/cmd/cnki@latest
   ```

2. 取得会话:

   ```shell
   cnki auth login
   ```

   弹出的浏览器窗口停在知网页面上, 在里面完成滑块验证即可. 需要题录导出与个人书房相关能力时, 顺便在该窗口内登录个人账号.

3. 验证:

   ```shell
   cnki auth status --probe
   cnki search 深度学习 --limit 5
   ```

   `--probe` 会实际访问一次知网, 报出"会话可用"即表示一切就绪.

## Features

**会话**

- 受控浏览器接管: 打开一个独立的 Chrome 窗口, 用户完成验证后自动读取会话并关闭窗口. 机构 IP 登录, 账号密码, 短信验证码, 微信扫码与 CARSI 联邦认证走的都是同一条路径, 不需要为每种登录方式单独实现协议.
- 会话失效自动接力: 命中验证跳转时按配置重新拉起验证窗口, 策略可选 `relogin` / `fail` / `prompt`, 脚本环境建议用 `fail` 以免卡在等人工操作上.
- 不方便开浏览器时的三条注入通道: `--cookie-string`, `--cookie-file`, `--from-curl`, 以及环境变量 `CNKI_COOKIE`. `--from-curl` 直接吃浏览器开发者工具里 "Copy as cURL" 的内容.
- 接管已有浏览器: `cnki auth login --cdp 9222` 复用日常浏览器里已经登录过的知网会话, 不新开窗口, 也不会关掉那个浏览器.
- 会话文件权限固定 `0600`, 只保存 `document.cookie` 能读到的那部分, 少存一份凭证就少一份泄漏面.

**检索**

- 一框式: `cnki search <关键词>`, 支持主题, 篇关摘, 关键词, 篇名, 全文, 作者, 第一作者, 通讯作者, 作者单位, 基金, 摘要, 小标题, 参考文献, 分类号, 文献来源与 DOI 共 16 个字段切换.
- 高级检索: `cnki adv --cond '主题=深度学习' --cond '作者单位=清华大学'`, 条件之间支持 AND, OR, NOT, 同一句与同一段.
- 专业检索: `cnki expr "SU=('深度学习'+'神经网络') AND AU=('张三')"`, 直接使用知网自己的检索表达式语法.
- 句子检索: `cnki sentence 大语言模型 医学影像`, 把命中的原句一并输出, 默认同一句, `--paragraph` 改为同一段.
- 作者发文检索: `cnki author 张三 --org 清华大学`.
- 排序与分页: 相关度, 发表时间, 被引与下载四种排序; 每页 10 / 20 / 50 条; `--limit` 控制取回上限.
- 文献库限定: `--db` 覆盖知网全部 33 个库, 从总库, 学术期刊, 学位论文到专利, 标准, 报纸, 年鉴, 法律法规与科技成果.
- 分组聚合: `cnki group` 支持主题, 来源类别, 学科, 研究层次, 年度, 文献类型, 文献来源, 作者, 机构, 基金与 OA 出版共 11 个维度; 检索命令也可以用 `--group` 顺带取回.
- 文献详情: `cnki detail` 抽取题名, 作者, 机构, 摘要, 关键词, 基金与分类号; 作者块里的机构会被识别出来单独存放, 不会混进作者列表.

**产出**

- 题录导出: `cnki export` 支持 `ris` 与 `bibtex` 本地渲染, 以及知网侧生成的 `gbt7714`, `reference`, `cnki`, `mla`, `apa`, `refworks`, `endnote`, `noteexpress`, `notefirst` 与 `custom`.
- BibTeX 引用键稳定可复现: 中文文献得到形如 `cnki2026a29305` 的键, 西文文献形如 `smith2024a3f9c1`, 重复导出同一批文献键不会变, 不会打断已有的 LaTeX 引用.
- 输出格式: `--format table|json|csv|markdown`, 或直接用 `--json`. CSV 带 UTF-8 BOM, Excel 打开中文不乱码.

**工程**

- 元信息自省: `cnki info dbs|fields|groups|sorts|formats|paths`, 参数取值不必翻文档.
- 配置带版本号与独立迁移模块, 首次运行自动生成 `~/.config/cnki-cli/config.toml`; 请求间隔, 超时, 默认输出格式, 浏览器路径与失效策略都可调.
- 退出码细分: 0 成功, 1 通用失败, 2 用法错误, 3 会话失效, 4 权限不足, 5 远端异常, 130 被中断.
- 日志走 `slog` 且只写 stderr, 支持 `--log-level` 与 `--log-format`; stdout 始终只承载结果本身.
- 请求默认间隔 1500 毫秒, 避免高频访问触发知网风控.
- 发布构建的版本号自动生成: 恰好停在 tag 上时显示该 tag, 非 tag commit 追加 7 位短 hash, 工作区有未提交改动时改用 `^` 分隔, 日常开发构建显示 `dev-build`. 归档前会跑 `--version` 冒烟断言, 注入失效时直接失败而不是产出错版本号的产物.
- CI 在 linux, macOS, Windows 的 x86_64 与 aarch64 六个原生 runner 上分别构建并上传产物, 只有 tag 推送才会创建 release.

## Known Limitations

- 知网只开放检索结果的前 300 页, 每页最多 50 条.
- 知网侧生成的题录格式需要登录个人账号. 机构 IP 态下请求会被重定向到登录页, 本工具会直接报出这一点并建议改用本地的 `ris` 或 `bibtex`, 而不会把登录页当作题录输出.
- 全文下载受订阅权限约束, 本工具只负责发起请求与落盘, 不绕过权限.
- 知网目前不校验检索接口的请求签名 (实测裸请求与带签名的请求返回一致), 本工具因此没有实现签名. 若知网日后开始强制校验, 需要补上等价的实现.
- 句子检索的检索项必须落在全文字段并共用一个检索项, 换一种构造方式会被知网判为"没有指定检索分类"; 这类约束来自知网接口本身, 不是本工具的选择.
- macOS 上 Chrome 无法在受限沙箱内运行 (会直接崩溃), 这种情况请在宿主环境直接执行, 或用 `--cdp` 接管已经开着的浏览器.
