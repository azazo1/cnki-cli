# 0.1.0

首个版本, 覆盖知网的检索体系.

## 检索入口

- 一框式检索, 支持 16 个检索字段的切换与排序, 时间范围与文献库限定.
- 高级检索, 多条件以 AND / OR / NOT / 同一句 / 同一段组合.
- 专业检索, 直接接受知网的检索表达式.
- 句子检索, 查找同时包含两个检索词的原句或段落, 并输出命中的原句.
- 作者发文检索, 支持作者与作者单位组合限定.
- 分组聚合, 覆盖主题, 来源类别, 学科, 研究层次, 年度, 文献类型, 文献来源,
  作者, 机构, 基金与 OA 出版共 11 个维度.
- 文献详情, 抽取题名, 作者, 机构, 摘要, 关键词, 基金, 分类号等字段.

## 产出

- 题录导出, 支持 GB/T 7714, MLA, APA, RefWorks, EndNote, NoteExpress,
  NoteFirst 等知网格式, 以及本地渲染的 RIS 与 BibTeX.
- 输出格式支持表格, JSON, CSV 与 Markdown. 表格按东亚字符宽度对齐.

## 会话

- 受控浏览器接管取得会话, 交互方式与 npm login 一致.
- 一条路径覆盖机构 IP, 账号密码, 短信验证码, 微信扫码与 CARSI 联邦认证,
  无需为每种登录方式单独实现协议.
- 会话失效时自动重新拉起验证窗口, 策略可配置为 relogin / fail / prompt.
- 支持从 cookie 字符串, 文件, cURL 内容或环境变量注入会话, 供远程与 CI 使用.
- 支持接管已开启远程调试的浏览器实例, 复用其中已有的登录状态.

## 工程

- 配置与日志分级, 日志只写 stderr 以保证 stdout 的管道可用性.
- 配置与会话文件各自带版本号与独立迁移模块.
- 请求限速与超时可配置, 避免触发知网风控.
- 单元测试不访问网络, 解析逻辑由按真实响应结构裁剪的 fixture 守护.
